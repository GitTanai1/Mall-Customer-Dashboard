# Mall Customer Analytics Dashboard

An interactive customer segmentation dashboard built using 
Microsoft Power BI Desktop, analysing 200 mall customers 
based on age, gender, income, and spending behaviour

## 📸 Dashboard Preview
![Dashboard](Customer%20segmentation.png)

##  Key Insights
- 26–35 age group has the highest spending score (64.45)
- Income does NOT predict spending behaviour
- 56% of customers are Female
- Middle income bracket is the largest segment (80 customers)
- Spending declines consistently with age

##  Tech Stack
- Microsoft Power BI Desktop (Free)
- Power Query Editor
- DAX (Basic Aggregations)
- Dataset: Mall_Customers.csv (200 rows × 5 columns)

##  Features
- 4 KPI Summary Cards
- Scatter Plot — Income vs Spending (5 clusters)
- Donut Chart — Gender Split
- Line Chart — Spending by Age Group
- Bar Charts — Income Bracket & Age Group
- Interactive Data Table

##  How to Use
1. Download Mall_Dashboard.pbix
2. Open with Microsoft Power BI Desktop (free)
3. Explore the dashboard interactively

##  Dataset
- Source: Mall_Customers.csv
- 200 customers, 5 fields
- Fields: CustomerID, Gender, Age, 
  Annual Income (k$), Spending Score (1-100)
